The City of Calder called your firm because the state's Cybersecurity Planning Committee gives grant priority to projects that retire unsupported software, and the clerk still works on a Windows 10 computer.

The clerk's computer still runs, and it no longer receives security updates. The computer, a Dell Inspiron 5567, runs Windows 10, and Microsoft's managers ended support for that version on October 14, 2025. The clerk cannot move to Windows 11, because Microsoft's engineers support it only on processors newer than the Inspiron's 7th-generation Intel Core i5.

In this chapter, you install Linux Mint on the clerk's computer and return it to the city ready for work. Before the install, you copy the clerk's files to a spare drive and boot a Linux Mint USB stick. After the install, you set up a login for the clerk and record the computer for the city.

Your firm gets jobs like this one because offices own working computers that Microsoft's engineers no longer support. You give each computer a current operating system, so the office receives security updates again. The client keeps the hardware it already paid for and buys no new machine.

The work gets tricky at four locks: Fast Boot, Secure Boot, a disk set to a mode called RAID, and BitLocker. You clear each lock in the setup screen or in Windows. On a computer as old as the clerk's, you turn Secure Boot off every time and change the other three only when you find one set.

This engagement comes first because every later job starts from a computer running Linux. In Chapter 2, you harden the clerk's computer. In later chapters, you move Calder's services onto Linux the city owns.
